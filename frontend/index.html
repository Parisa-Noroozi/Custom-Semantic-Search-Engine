Search Engine

Custom Semantic Search Engine

This project is a custom-built search engine developed from scratch using Python and FastAPI. Instead of relying on external AI embedding libraries, it implements its own semantic ranking pipeline to demonstrate how modern search systems work internally.

Tokenizer

Breaks the user's query into clean searchable words by removing punctuation, converting text to lowercase and preparing it for the search pipeline.

Intent Detection

Identifies the user's search purpose such as learning resources or PDF files and adjusts the ranking accordingly.

Query Expansion

Expands the original query using manually defined synonyms and related terms to retrieve more relevant documents.

Custom Embedding

Represents concepts as handcrafted semantic vectors based on manually designed knowledge relationships instead of pretrained AI models.

Semantic Similarity

Compares the semantic vectors of the query and documents using cosine similarity to measure conceptual closeness.

Relation Bonus

Rewards documents that contain concepts directly related to the user's query according to the knowledge base.

Category Bonus

Rewards documents that belong to the same semantic category as the searched concept.

BM25 Ranking

Ranks documents using keyword frequency and document statistics before semantic reranking is applied.

Final Ranking

Combines BM25, semantic similarity, relation bonus, category bonus and intent bonus into one final score.

Developer Mode

Displays every intermediate step of the ranking pipeline including tokenization, expansion, semantic scores and ranking explanations.
